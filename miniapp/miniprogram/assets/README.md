# Homepage assets

`images/study-abroad-hero.jpg` is a promotional illustration generated with the built-in image generation tool, not a photograph of a named university. Brief: natural editorial photograph of an adult Chinese student holding green books on the right, fictional modern Malaysian campus and palm leaves behind, pale sky on the left for readable UI text, no text or logos. Compressed to JPEG for the miniapp.

Icons are original vector drawings rendered to native-compatible PNG by `scripts/build-miniapp-icons.cjs`. University logos and campus photographs remain the existing approved website assets resolved by `services/university-media.ts`; missing campus photographs are not substituted with unrelated campuses.
