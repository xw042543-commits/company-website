# 账号管理

高级管理员登录后，进入「管理后台 → 账号管理」（`/zh/admin/accounts`）。普通管理员、顾问和普通用户不可进入；接口也会核对当前权限。沿用现有高级管理员授权，不开放注册或升级高级管理员的入口。

## 日常操作

1. 按姓名、邮箱或手机号搜索，配合账号状态、当前身份筛选；支持分页。
2. 点击「查看详情」核对账号编号、联系方式、注册时间和当前身份，并查看该用户的操作记录。
3. 已启用的普通用户可「设为管理员」；普通管理员可「取消管理员」。点击后须再次确认。
4. 「禁用」会阻止登录并撤销现有网页会话及小程序访问、刷新令牌。「启用」后须重新登录；待验证账号仍须完成原有验证。
5. 页面底部显示操作日志，包括操作人、目标账号、修改前后内容及时间。关闭详情后显示所有账号的日志。

当前账号不能修改自身身份或启用状态。已注销账号仅可查看。高级管理员和顾问的身份变更沿用原有专用授权流程，本页面只在普通用户与普通管理员之间调整。禁用高级管理员不会删除其原有高级授权，恢复并重新登录后仍按原有授权判断。

若提示「账号已被其他操作更新」，刷新后核对最新状态，再次确认。用户资料、申请与订单均保留，没有删除账号或修改个人资料的操作。

## 部署

按项目现有流程部署同一版本后端与前端。后端启动时执行新增 Flyway `V55__account_management_audit.sql`，仅新增日志表和索引，不调整现有账号身份，也不修改已执行迁移。不需要增加环境变量或公开管理员注册。部署后使用既有高级管理员验证入口，并使用专用测试用户检查升降级、禁用、恢复及旧会话失效；勿使用有真实业务的用户测试。


## 编辑用户名与头像

在其他账号右侧点击「编辑」，弹窗显示账号编号、邮箱、状态、当前用户名和头像。邮箱只读。修改用户名后可直接保存，也可上传JPG/PNG/WebP图片；原文件超过1MB会立即提示“头像大小不能超过1MB”，不会上传。

选择图片后，通过缩放、水平位置、垂直位置滑块调整正方形裁剪预览。保存时生成512×512头像并自动压缩到1MB以内。「删除头像」将在保存后显示默认头像；「恢复原头像」撤销本次头像选择。点击「取消」或关闭弹窗不会保存。失败保留原账号资料和头像，可按提示重试；版本冲突需重新打开编辑读取最新资料。

保存成功后列表和详情立即更新。导航与个人中心使用最新数据库资料，同浏览器页面立即同步；其他浏览器可见页面在5秒内自动刷新，重新聚焦立即同步。刷新或重新登录后继续显示最新资料。资料编辑不改变身份和启用状态，也不强制用户退出。

部署需同版本更新前后端，并执行新增V65迁移。无需新增存储凭据或环境变量，复用已有APP_MINIAPP_PUBLIC_ORIGIN配置头像域名；生产应保持现有HTTPS网站域名。编辑功能不允许在此入口编辑自身或已注销账号，也不能设置高级管理员。
