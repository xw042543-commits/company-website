# 马来西亚专业官网数据试点

核对日期：2026-10-14

## 数据库现状

通过公开只读 API 核对到 20 所已发布的马来西亚院校、2,233 个已发布专业。基础字段缺失统计如下：

| 字段 | 缺失专业数 |
| --- | ---: |
| 英文专业名 | 896 |
| 学制 | 627 |
| 学费 | 532 |

完整审计结果保存在本地忽略目录 `.data/audits/`，避免把线上数据快照长期提交到仓库。

## 马大试点结果

试点来源仅使用 Universiti Malaya 官方站 `study.um.edu.my`。爬虫遵守 `robots.txt`，请求间隔为 2 秒，共保存 140 个 HTML 快照。

| 项目 | 数量 |
| --- | ---: |
| 官网本科候选 | 79 |
| 与现有数据库唯一匹配 | 76 |
| 有详情页证据并生成增量数据 | 72 |
| 专业更新记录 | 72 |
| 详情板块记录 | 216 |
| 入学时间候选 | 132 |
| 匹配歧义 | 0 |
| 已有学制或学费冲突 | 0 |

增量迁移为 `V34__import_um_official_programme_details.sql`。它只填补空字段；已有真实介绍、学制、学费和来源不会被覆盖。历史无来源的生成式介绍或详情内容可由官网英文原文替换。新详情板块发布为 `PUBLISHED`，并记录 `source_url` 和 `source_checked_at`。

## 未自动导入

以下 3 个官网专业未在现有马大专业中找到唯一对应项：

- Bachelor of Islamic Studies and Science
- Bachelor of Islamic Education
- Bachelor of Science with Education

现有表要求每个专业必须关联内部学科分类。官网只能提供院系原文，无法可靠确定内部分类代码，因此本次不猜测、不新增，保留在对账失败记录中等待审核。

官网入口批量探测还记录了 8 个访问失败来源：UCSI、SEGi、Monash 和 MAHSA 的 `robots.txt` 返回 403，USM 与 UUM 的 `robots.txt` 返回 500，UTAR 请求失败，City University 入口返回 403。采集器按规则停止这些来源，没有绕过限制。

## 试点后的首批扩展

马大验证通过后，继续处理了 Taylor's University。80 个官网页面经 URL 去重后得到 62 个候选，与数据库唯一匹配并有详情页证据的专业为 29 个，生成 87 条官方详情板块和 114 条入学时间候选。其余官网候选包含数据库尚未收录的专业、文凭、语言课程和研究生项目，或名称无法唯一对应，因此没有自动导入。

泰莱官网同时展示本地生 MYR 学费和国际生 USD 学费。迁移仅把明确标记为 `International` 的费用作为候选；现有数据库学费使用 MYR，两者被记录为币种冲突且不会自动覆盖。课程结构、入学要求和就业方向来自各专业详情页，并记录官网链接和核对时间。

随后检查了 Asia Pacific University。官网 100 个页面可正常读取，但现有 71 条数据库专业只有中文名称且没有官网 URL，官网页面又没有可由通用解析器识别的课程结构化标记。为避免用翻译或相似度猜测关联，本批次不生成 APU 导入 SQL；需先建立经人工审核的中英文名称或官网 URL 对照表，再重放已保存快照。

## 复用流程

1. `scripts/audit-malaysia-programmes.mjs` 从公开 API 只读审计现有院校、专业和缺失字段。
2. `crawler` 按白名单官网、`robots.txt` 和限速规则保存原始快照及字段级证据。
3. `reprocess` 在适配器更新后重放快照，无需重复访问官网。
4. `reconcile` 规范化名称、唯一匹配、检查冲突和字段长度，并生成只填空值的 Flyway SQL。
5. 未匹配、歧义、冲突和抓取失败进入 JSON 报告，不能自动发布。
6. SQL 经过审查和测试后随应用部署，由 Flyway 执行；工具本身不连接生产数据库。

后续学校需逐校增加官网页面适配器。`crawler/config/sources.malaysia.current.json` 已与数据库当前 20 所马来西亚院校对齐，可用于分批采集和失败重试。
