# 网站项目需老板提供的资料清单

更新日期：2026-09-18

## 一、最高优先级：没有这些资料，核心功能无法正式上线

### 1. 公司与联系方式

- 公司正式中文名称
- 公司正式英文名称
- 公司注册名称与注册编号
- 办公地址
- 对外联系电话
- 对外联系邮箱
- 微信号或企业微信联系方式
- 营业时间与可联系时段
- 负责处理网站咨询的员工姓名或岗位

### 2. 咨询表单与隐私资料

第一版咨询表单已按 Q31 A 规划收集：

- 姓名
- 手机号或微信号
- 意向学校
- 意向专业
- 学历层次
- 备注
- 隐私同意

仍需老板确认和提供：

- 隐私政策正式文本
- 表单隐私同意文字
- 个人资料保存期限
- 谁可以查看咨询资料
- 用户要求删除或更正资料时的联系方法
- 咨询提交后的预计回复时间，例如 1 个工作日内
- 邮件通知收件人
- 企业微信通知群或应用负责人
- 企业微信 Webhook 或应用配置，由负责人通过安全方式配置，不要写入公开文档
- 是否同时发送邮件和企业微信通知

### 3. 院校与专业 Excel 正式数据

#### 院校资料字段

- 院校唯一编号
- 中文名称
- 英文名称
- 老板批准的中文、英文、缩写别名
- 国家
- 城市
- 校区
- 院校中文介绍
- 院校英文介绍
- 官方网站
- 官方院校 Logo
- Logo 使用授权或来源
- 是否为真实合作院校
- 如果是合作院校，可公开使用的合作关系表述
- 资料来源链接
- 资料最后核对日期
- 审核人
- 发布状态

#### 专业资料字段

- 专业唯一编号
- 所属院校编号
- 中文专业名称
- 英文专业名称
- 老板批准的搜索别名
- 专业分类
- 学历层次
- 授课模式
- 授课语言
- 学制
- 入学年月
- 学费金额
- 币种
- 学费计算周期，例如每年、每学期或全课程
- 申请要求
- 英语要求
- 专业中文介绍
- 专业英文介绍
- 官方资料来源链接
- 资料最后核对日期
- 审核人
- 发布状态

## 二、高优先级：固定导航页面需要的正式内容

### 1. 语言

- 提供哪些语言课程或考试辅导
- IELTS、TOEFL、PTE 或其他考试范围
- 课程形式
- 适合人群
- 上课时间
- 费用
- 报名方式
- 负责老师或咨询入口

### 2. 奖学金

- 奖学金名称
- 对应院校或机构
- 适用学历层次
- 金额或减免比例
- 申请条件
- 截止日期
- 申请流程
- 官方来源链接
- 资料最后核对日期

### 3. 留学项目

- 项目名称
- 国家与院校
- 项目类型
- 适合人群
- 开始和结束日期
- 报名截止日期
- 费用
- 包含与不包含的项目
- 名额
- 申请条件
- 退款规则
- 联系方式
- 官方图片

### 4. 新闻

- 新闻标题
- 中英文正文
- 发布日期
- 作者或来源
- 封面图片
- 图片授权
- 分类
- 是否置顶

### 5. 关于我们

- 公司正式介绍
- 成立时间
- 服务范围
- 团队介绍
- 顾问姓名、职位、照片与简介
- 可公开的真实服务经验
- 可公开的真实成功案例
- 办公室与团队照片
- 公司价值观
- 可验证的资质、奖项或认证

## 三、品牌与网站素材

- 已确认的 UDAJO Logo 原始文件，优先 SVG 或透明 PNG
- Logo 横版、竖版、深色背景和浅色背景版本
- 品牌标准色与辅助色
- 可公开使用的首页主视觉照片
- 办公室照片
- 团队照片
- 学生活动照片
- 每张图片的使用授权或来源
- 企业微信或微信咨询二维码
- 社交媒体账号链接
- 不可以使用的品牌表达或图片

## 四、首页文案需要确认

- 首页主标题
- 首页副标题
- UDAJO 的核心服务定位
- 为什么选择 UDAJO 的正式理由
- 申请流程是否保持现在的五个步骤
- 咨询按钮正式用词
- 是否可以公开展示客户评价
- 如展示评价，需要真实姓名显示方式、评价内容和授权
- 是否有可以公开的真实数据，例如服务年限、申请数量或录取结果

没有证据支持的数据不应放到网站。

## 五、页脚、法律与上线资料

- 公司版权名称
- 当前版权年份显示方式
- 隐私政策
- 网站使用条款
- Cookie 或分析工具说明
- 公司注册信息
- 投诉与资料保护联系邮箱
- 网站域名
- 网站部署账号负责人
- 如面向中国大陆公开访问，确认是否需要 ICP 备案或其他合规资料
- Google Analytics、Meta Pixel 或其他统计工具是否启用

## 六、搜索与筛选规则

- 完整的老板批准别名表
- 国家别名，例如 UK 对应 United Kingdom
- 专业别名，例如 CS 对应 Computer Science
- 中文专业名称对应的正式英文名称
- 拼写错误是否允许模糊匹配
- 哪些短缩写必须精确匹配
- 搜索结果排序规则
- 热门院校的定义
- 专业分类完整列表
- 授课语言完整列表
- 学历层次完整列表
- 学费筛选按年、学期或完整课程计算
- 多选筛选是否允许

## 七、建议老板优先交付的顺序

1. 公司联系方式、咨询负责人、隐私政策和通知对象
2. 正式院校与专业 Excel 数据
3. 关于我们、语言、奖学金、留学项目和新闻内容
4. 咨询二维码、团队照片、办公室照片和首页主视觉
5. 法律资料、域名、统计工具和最终上线账号

## 八、提交资料时的要求

- 文案需标明中文、英文或是否需要项目组翻译
- 图片需提供原始文件，不要只发聊天软件截图
- 每条事实资料需附官方来源或负责人确认
- 每份资料需写明最后更新时间
- 每项内容需标明可以公开、内部使用或暂不发布
- 院校与专业资料请使用项目组提供的统一 Excel 模板
