# 公开文章接口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为语言、奖学金、留学项目、新闻提供仅公开已发布内容的分页列表与详情接口。

**Architecture:** PostgreSQL `content_articles` 是唯一数据源；`ArticleRepository` 负责带发布时间约束的查询，`ArticleService` 负责分页校验与 DTO 映射，`ArticleController` 暴露 `/api/v1/articles`。不建立写接口或示例内容。

**Tech Stack:** Java 21、Spring Boot 4.1.1、Spring Data JPA、Flyway、PostgreSQL 17、JUnit 5、MockMvc、Testcontainers。

**Spec:** `docs/superpowers/specs/2026-09-22-public-articles-api-design.md`

## Global Constraints

- 仅支持 `language`、`scholarships`、`programmes`、`news` 四个栏目。
- 仅公开 `PUBLISHED` 且 `published_at <= now` 的文章。
- 不提供登录、管理、导入、上传、搜索、缓存或虚构文章。
- 中英文内容缺失时返回 `null`，Markdown 作为文本返回。
- 保留现有 `PageResponse`、`ApiErrorResponse` 和 `X-Trace-Id` 约定。
- Git 提交和推送由项目负责人执行；实现步骤不自动提交。
