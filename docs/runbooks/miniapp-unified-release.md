# 小程序 A/B/C 统一版本

集成基于 `main`（专业、规划、个人中心和原生兼容修复），合入 `feat/miniapp-v1`（首页、院校、U圈和顾问审核）。正式交付以本次集成 PR 合入后的 `main` 为准，不能再分别部署旧功能分支。

## 数据库升级

- 保留 `main` 已发布的 V1–V16 迁移内容及编号。
- U圈建表使用 V17，持久化提交回执使用 V18，避免与专业详情、媒体、用户资料迁移重号。
- 部署前确认数据库 Flyway 历史与 `main` 一致并验证备份。若曾直接部署旧 U圈分支、数据库 V14/V15 已是社区迁移，先停止升级并单独制定迁移方案；不要删除历史或执行 Flyway repair 来掩盖差异。
- 生产配置须提供所有副本共享的 `APP_COMMUNITY_CURSOR_SECRET`。U圈写入默认关闭，政策与运维条件确认后再启用。

## 集成验收

- 首页 → 院校筛选 → 院校详情 → 专业详情，核对所选课程及院校。
- 微信登录 → 规划提交 → 规划记录；咨询提交 → 咨询记录 → 顾问后台。
- 个人中心同时保留收藏、规划、咨询及 U圈个人内容入口。
- U圈浏览、发布、评论、点赞、举报，以及顾问审核、冲突刷新。
- 微信开发者工具及真机检查导航、原生组件、键盘、安全区、弱网和登录续期。

CI 增加小程序测试、类型检查和 lint，与后端、网站及部署检查共同作为集成验证。实际真机和容量压测仍是上线前验收，自动测试不替代这些结果。
