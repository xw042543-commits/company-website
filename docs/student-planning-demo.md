# 学生规划离线演示

## 当前默认入口：直接聊天

`planning-agent.html` 现在进入即可聊天，不再要求填背景表、选择年龄或勾选后才能开始。页面持续说明预设模拟、非真实 AI、不联网、勿输入真实隐私资料。

`scripts/planning-chat-demo.ts` 提供有限关键词的预设回复，支持学历、预算、专业方向、语言等交互；不是语义模型。每轮最多一个可跳过问题，仅保留明确目标学历与币种，不猜测成绩，不承诺录取或判断真实费用。未知问题会说明演示限制。

保存需要用户主动确认，仅在本页内存保存对话快照；历史只读。模拟转顾问只展示用户说过的话，不收联系方式，也不发送资料。更多菜单中可以模拟失败、重试、清空；重置会取消旧回复，刷新会清空历史。Enter 发送、Shift+Enter 换行，输入法组合输入时不发送。

构建命令不变：在 `miniapp` 执行 `node --import tsx scripts/preview-planning-agent.ts`。新增测试：`node --import tsx --test tests/planning-chat-demo.test.ts`。这是独立预览适配，不修改小程序入口和运行时，也不代表已接入真实 AI、招生数据或上线。

## 旧表单原型（仅 legacy 入口）

以下记录仅适用于 `planning-agent-legacy.html`，不再是默认学生流程。

这是预设数据的浏览器演示，不是真实 AI 服务。没有模型调用、外部 API 请求或真实咨询提交。复用现有 Page 控制器，但所有新增行为都在 `miniapp/scripts` 的预览适配层；不改变小程序运行时或入口。

在 `miniapp` 目录运行 `npx tsx scripts/preview-planning-agent.ts`，通过本地静态服务器打开 `.preview/planning-agent.html`。若环境禁止 tsx CLI 的 IPC，可使用 `node --import tsx scripts/preview-planning-agent.ts`。

输入第一句话后发送，按提示选择年龄并确认演示说明。可用顶部学历选择器填入预科、本科、硕士或博士示例，检查背景并勾选确认，然后生成演示方案。首次发送的文字会保留，并在首次生成时作为请求文字加入对话；文字不会自动推断或修改背景。任意对话仅返回预设的背景确认提示。

方案、院校、专业、来源与费用均为虚构。所有专业分类为 UNKNOWN、资格判定为 false，来源为 MOCK 且没有官方链接。四个学历使用同一组模拟费用：MYR 126000（84000 学费、36000 生活费、6000 税费）或 MYR 100000（66000、30000、4000）；仅用于展示总额计算，不代表真实学制、税率或完整留学成本。只有 MYR、全程总预算、包含生活费且预算大于零时才进行模拟预算比较。缺失或不支持的学历返回空方案。

浏览器发送/生成固定等待约 700ms，方便观察发送状态；测试默认无延迟。点击“模拟下次失败”会让下一次新消息接受返回 NETWORK_UNAVAILABLE；使用页面“重试”沿用控制器原有 requestKey，不重复生成消息、运行或保存。成功后可勾选保存、查看本页历史，再演示顾问交接；请使用虚构联系方式。

数据只保存在当前页面内存。刷新或重置清空会话、方案、身份与重试缓存；重置同时取消等待并使旧请求失效，旧结果不能重新写回。页面历史不会跨刷新保留。Enter 在输入法组合输入期间不会发送。

自动验证：`node --import tsx --test tests/planning-agent-demo.test.ts`，完整检查：`npm run check`。浏览器交互和实际微信设备是不同验证范围，本演示不构成真机或上线验收。
